# Tap List India

The best Indian craft beers this week, this month, this year and across five years, what to eat with each one, and where to drink it. Pick a city, pick a window, and the list and the map both update.

It is a static site with no build step, so GitHub Pages hosts it for free.

## Where the ratings come from

From drinkers, through GitHub. Every beer has a **Rate it** link that opens a prefilled issue. A maintainer checks it and adds a line to `data/ratings.json`:

```json
{ "beer": "tintin-toit", "score": 4.5, "date": "2026-09-20" }
```

It does not scrape Zomato, Swiggy, Untappd or RateBeer. None of them offers an open API (Zomato closed its API in 2021, Untappd no longer accepts new API applications), and scraping them breaks their terms. The site links out to all of them instead.

The ratings file currently holds **sample data**, generated by `scripts/sample_ratings.py` and flagged on the page. Delete it once real ratings arrive.

## How the ranking works

`rank.js` takes a Bayesian average. Every beer starts with five imaginary ratings of 3.5, so a single lucky 5 cannot beat a beer that has scored 4.5 twenty times. Change `PRIOR_MEAN` and `PRIOR_WEIGHT` to tune it.

## Adding a brewery or beer

- Taproom: add it to `data/venues.json` with `city`, `area`, `lat` and `lng`.
- Bottled or canned brand: use `"kind": "packaged"` with a `cities` list instead.
- Beer: add it to `data/beers.json` with a `style` from the pairing list in `app.js`.

## Run it locally

```sh
python3 -m http.server 8000   # then open http://localhost:8000
node rank.test.mjs            # ranking check
```
